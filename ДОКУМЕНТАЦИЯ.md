# Wist — документация

> Персональный хаб памяти для Windows. Четыре вида памяти в одном тёмном, тихом месте: то, что вы **смотрите** (аниме, фильмы, сериалы, YouTube), **читаете** (книги), **думаете** (записи с [[вики-ссылками]]) и **чувствуете** (моменты со скриншотами). «Древо памяти» превращает ваш год в живое дерево, где каждый лист — воспоминание. Все данные хранятся локально — никаких облаков и аккаунтов.

---

## 1. Установка

### Способ 1 — установщик (рекомендуется)

1. Откройте папку `release` в корне проекта и запустите **`Wist Setup 0.3.0.exe`** (или скачайте установщик из [Releases на GitHub](https://github.com/spilpix/Wist/releases)).
2. Windows SmartScreen может показать синее окно «Система Windows защитила ваш компьютер» — это нормально для неподписанных программ. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите язык установщика (русский или английский).
4. Выберите папку установки (по умолчанию `C:\Users\<вы>\AppData\Local\Programs\Wist`) и нажмите «Установить».
5. После установки ярлык **Wist** появится на рабочем столе и в меню «Пуск».

При первом запуске язык интерфейса подхватится из системы (русский), его можно сменить в **Настройки → Внешний вид → Язык интерфейса**.

### Способ 2 — из исходников (для разработки)

```sh
npm install      # зависимости; нативные модули скачиваются как prebuilds — компилятор не нужен
npm run dev      # запуск в dev-режиме с горячей перезагрузкой
```

### Обновление / удаление

- **Обновить**: соберите новый установщик (`npm run dist`) и запустите его поверх — данные не теряются, они лежат отдельно (см. раздел «Данные»).
- **Удалить**: «Параметры → Приложения → Wist → Удалить». База и скриншоты останутся в `%APPDATA%\Wist` — удалите вручную, если нужно.

## 2. Первые шаги

1. **Добавьте тайтл**: Библиотека → «Добавить тайтл» — название, тип (аниме/фильм/сериал/мультсериал/YouTube), статус, количество эпизодов, год, жанры, обложка (перетащите картинку прямо в форму).
2. **Импортируйте видео**: Источники → Локальные файлы → «Добавить файлы» или «Добавить папку». Wist сам распознает название и номер серии из имени файла и предложит сопоставление — проверьте и нажмите «Импортировать».
3. **Смотрите**: нажмите Play на тайтле — встроенный плеер запомнит позицию, отметит серию просмотренной на 85% и предложит следующую.

### Какие имена файлов понимает парсер

| Шаблон | Пример |
| --- | --- |
| `[Группа] Название - 14 [1080p].mkv` | `[SubsPlease] Frieren - 14 [1080p].mkv` |
| `Название.S02E07.mkv` | `Severance.S02E07.1080p.mkv` |
| `Название - Episode 14.mkv` | `One Piece - Episode 1071.mkv` |
| `Название_ep14.mkv` | `Lain_ep07.mkv` |
| `Название 14.mkv` и другие вариации | `Монолог фармацевта 03.mkv` |

Поддерживаемые форматы: `.mkv`, `.mp4`, `.avi`, `.mov`, `.webm`.

## 3. Страницы приложения

| Страница | Что делает |
| --- | --- |
| **Главная** | «Продолжить просмотр», недавно добавленные, личная статистика, хитмап активности за год |
| **Библиотека** | Сетка/список всех тайтлов. Фильтры: тип, статус, жанр, год, рейтинг. Сортировка и мгновенный поиск |
| **Книги** | Библиотека с фильтром «книги»: главы вместо эпизодов, прогресс чтения кнопками −/+ |
| **Продолжить просмотр** | Серии, брошенные на середине, с прогресс-баром и кнопкой «продолжить с того же места» |
| **Избранное** | Тайтлы с вашей оценкой 9–10 |
| **Моменты** | Все сохранённые кадры: фильтр по тегу и тайтлу, переход к моменту в плеере, экспорт всех в папку |
| **Записи** | Стена заметок: закрепление, теги, поиск, привязка к тайтлу, [[вики-ссылки]] на тайтлы и другие записи |
| **Древо памяти** | Год как живое дерево: 12 ветвей-месяцев, листья — моменты, завершённые тайтлы, книги и записи. Клик по листу открывает воспоминание |
| **Локальные файлы** | Импорт файлов/папок, сканирование медиапапок из настроек |
| **YouTube** | Привязанные каналы/плейлисты, список видео через yt-dlp, ручные отметки «просмотрено» |
| **Статистика** | Тайтлы/эпизоды/часы/дни, разбивка по типам, время по месяцам, топ по рейтингу, стрики |
| **Настройки** | Медиапапки, папка скриншотов, субтитры, автоплей, тема (тёмная/светлая/системная), язык, акцентный цвет, экспорт/импорт данных |

### Командная палитра — Ctrl+K

Нажмите **Ctrl+K** (или кликните по строке поиска в шапке окна) — откроется быстрый поиск в духе Notion: страницы приложения, действия («Добавить тайтл», «Новая запись», «Переключить тему») и мгновенный поиск по тайтлам и записям. Стрелки — навигация, Enter — открыть, Esc — закрыть.

### Темы

Тёмная, светлая или системная — переключается кнопкой ☀️/🌙 в шапке окна, через Ctrl+K или в Настройках → Внешний вид. Тема применяется мгновенно, включая цвет системных кнопок окна, и запоминается между запусками.

## 4. Плеер

- Запоминает позицию каждого файла, возобновляет с того же места.
- Авто-отметка «просмотрено» на 85% серии; автопереход к следующей с обратным отсчётом 5 секунд.
- Субтитры: автоматически находит `.srt`/`.ass` рядом с видео (RU/EN распознаются по имени файла).
- **Пропустить заставку**: один раз отметьте конец опенинга кнопкой-флажком — кнопка появится в каждой серии тайтла.
- **Моменты на таймлайне**: сохранённые моменты видны точками на полосе перемотки, клик — переход.
- Если файл не декодируется (HEVC/10-bit) — кнопка «Открыть в mpv» (путь к mpv задаётся в настройках).

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` / `K` | пауза / воспроизведение |
| `←` / `→` | −10 / +10 секунд |
| `↑` / `↓` | громкость |
| `F` | полный экран |
| `M` | звук вкл/выкл |
| `S` | скриншот кадра в PNG |
| `B` | **сохранить момент** (кадр + заметка + тег) |
| `N` / `P` | следующая / предыдущая серия |
| `Esc` | назад |

### Моменты

`B` или кнопка-закладка: плеер ставит паузу, захватывает кадр, вы пишете заметку («Что здесь произошло?») и выбираете тег — Эпично / Смешно / Грустно / Важно / Красиво. Все моменты собираются на странице «Моменты», откуда можно прыгнуть точно в эту секунду серии.

## 4½. Записи и Древо памяти

### Записи

«Записи» — это лёгкие заметки в духе Obsidian, но оформленные как стена карточек:

- **Создание**: кнопка «Новая запись» — заголовок, текст, теги, привязка к тайтлу из библиотеки.
- **[[Вики-ссылки]]**: напишите `[[Название тайтла]]` или `[[Заголовок другой записи]]` в тексте — ссылка станет кликабельной и откроет тайтл или запись.
- **Закрепление**: пин выносит запись в раздел «Закреплённые» с фиолетовой рамкой.
- **Сохранение**: автоматически при закрытии панели (или Ctrl+Enter).
- Поиск и фильтр по тегам — мгновенные.

### Книги

Добавьте тайтл с типом «Книга»: вместо эпизодов — главы. На странице книги — блок «Прогресс чтения» с кнопками −/+ и кнопкой «Отметить прочитанной». Дочитанная книга автоматически получает статус «Завершено» и попадает на Древо памяти.

### Древо памяти

Страница «Древо памяти» рисует последний год как дерево: ствол, 12 ветвей-месяцев, и листья:

- 🟣 фиолетовый — сохранённый момент
- 🟢 зелёный — завершённый тайтл
- 🟠 янтарный — прочитанная книга
- 🔵 голубой — запись

Чем насыщеннее месяц, тем длиннее ветвь. Наведите на лист — увидите, что это было; кликните — откроется тайтл или запись.

## 5. YouTube

1. Откройте любой тайтл → раздел «YouTube-источники» → вставьте ссылку на канал или плейлист.
2. Кнопка «Обновить» подтягивает список видео через **yt-dlp** локально, без API-ключей.
3. Видео отмечаются просмотренными вручную; «Смотреть на YouTube» открывает браузер.

Установка yt-dlp: `winget install yt-dlp` (или укажите путь в Настройках).

## 6. Данные и резервные копии

| Что | Где |
| --- | --- |
| База данных | `%APPDATA%\Wist\wist.db` |
| Настройки | `%APPDATA%\Wist\settings.json` |
| Обложки | `%APPDATA%\Wist\covers\` |
| Скриншоты и моменты | `%APPDATA%\Wist\screenshots\` (меняется в настройках) |

- **Экспорт**: Настройки → Данные → «Экспорт всех данных» — один JSON со всей библиотекой, историей и моментами.
- **Импорт**: «Импорт резервной копии» — полностью заменяет текущие данные содержимым копии.
- **Очистка истории**: удаляет сессии и прогресс, не трогая тайтлы и моменты.

## 7. Сборка из исходников

Требования: Node.js 18+ и npm. Компилятор C++ **не нужен** — `.npmrc` настроен на скачивание готовых бинарников под Electron.

```sh
npm install          # зависимости
npm run dev          # разработка (Vite + Electron, горячая перезагрузка)
npm run typecheck    # проверка типов
npm run build        # продакшен-бандлы
npm run icon         # перегенерировать иконку из build/icon.svg
npm run dist         # собрать установщик → release/Wist Setup <версия>.exe
```

> ⚠️ Если обновляете версию Electron в `package.json` — обновите `target` в `.npmrc`, иначе `npm install` попытается компилировать better-sqlite3 и упадёт.

### Как добавлять новые строки интерфейса

Все тексты живут в `src/i18n/en.ts` и `src/i18n/ru.ts`. Добавьте ключ в оба файла и используйте `const { t } = useI18n()` в компоненте. Если забыть перевод в `ru.ts` — проект не пройдёт проверку типов (это специально).

## 8. Частые вопросы

**Видео не воспроизводится / чёрный экран.**
Кодек не поддерживается Chromium (чаще всего HEVC/H.265 10-bit). Установите mpv (`winget install mpv`), укажите путь в Настройках и используйте «Открыть в mpv».

**YouTube-источник не синхронизируется.**
Не установлен yt-dlp или он не в PATH. `winget install yt-dlp`, либо пропишите полный путь в Настройках.

**SmartScreen ругается на установщик.**
Установщик не подписан сертификатом (подпись стоит денег). «Подробнее» → «Выполнить в любом случае».

**Как перенести всё на другой ПК?**
Экспортируйте данные (Настройки → Данные), скопируйте папку скриншотов, на новом ПК установите Wist и импортируйте копию. Пути к видеофайлам должны совпадать, иначе укажите файлы заново через импорт.

**Где сменить язык?**
Настройки → Внешний вид → Язык интерфейса (русский/английский, применяется мгновенно).
