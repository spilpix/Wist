# Bard — Session Handoff

> Hand this file to a new chat so it picks up exactly where we left off.
> Project: **Bard** (formerly Wist) — a local-first desktop "second brain" / media hub.
> Current version: **0.25.0**. Branch: `main` (NOT pushed to GitHub). Rollback point: branch `backup/main-0.8.0`.

## 1. What Bard is
A Windows desktop app for a video editor / motion designer (Blender, DaVinci, After Effects, Photoshop) who games, works with AI, and watches anime. It's his "second brain": projects + references, notes with Obsidian-style links, tasks, journal, library/anime tracking with watch-time stats, music links, files vault, a knowledge graph, an infinite canvas, and a Steam-style games playtime tracker.

## 2. Stack & architecture
- **Electron 33** + **React 18** + **TypeScript** + **Vite** + **TailwindCSS**, **better-sqlite3** (local DB), **zustand** (state), **d3-force** (graph).
- Native modules use prebuilds via `.npmrc` (electron ABI) — `npmRebuild: false`. No compiler needed.
- **Data pattern (follow it for everything new):** SQLite table → `electron/db/<x>.ts` (CRUD) → IPC channel `x:action` registered in `electron/ipc/index.ts` → exposed in `electron/preload.ts` as `window.wist.x.*` → typed in `src/types/api.ts` (`WistApi`) → consumed via a zustand store or directly in `src/pages/*`.
- **Migrations:** versioned SQL array in `electron/db/database.ts` (currently up to **007**). Additive (CREATE / nullable ADD COLUMN) is safe with FK on; table rebuilds need FK off.
- **i18n:** `src/i18n/en.ts` + `src/i18n/ru.ts`. `ru` is `Record<keyof typeof en, string>` — **add every key to BOTH** or typecheck fails. Use via `useI18n()` `t('key', params)`.
- **Design system:** primitives in `src/components/ui/` — `Button, IconButton, Chip, Badge, PageHeader, Tabs, SectionHeader, Card, Modal, ConfirmDialog, EmptyState, Spinner, ChipsInput, Toaster`. Tokens (theme CSS vars) in `src/index.css`, remapped in `tailwind.config.cjs` (semantic `bg/surface/raised/edge`, `zinc-*`+`white` flip with theme, `accent`/`accent-bright`). Build new UI from these.
- **Theme (Claude brand palette, as of 0.23.0):** dark default (base `#1E1A17` / surface `#252018` / card `#2C2418` / border `#3A3028`; text `#FFF5E1`/`#B1ADA1`/`#6A6058`); light = warm off-white (`#FAF9F5`/`#F4F3EE`/`#FFFFFF`, text `#3C2F23`/`#847A6D`/`#B1ADA1`). **Accent is THEME-SPECIFIC: Crail `#C15F3C` on light, Tangerine `#E67D22` on dark** — accentColor `''` = "brand" → `applyAccent` picks per-theme (BRAND map in `settingsStore.ts`); a non-empty hex is a user override (hover/bright derived). Tokens added: `--card`, `--input-bg` (→ `bg-field`), `--highlight`, `--accent-subtle`, `--accent-hover-rgb` (→ `bg-accent-hover` on `.btn-accent`); `.card`→`bg-card`, `.input`/`.select`→`bg-field`. `text-muted` (zinc-600) is intentionally low-contrast per the user's spec (placeholders/hints). `settingsStore.load()` migration self-heals legacy default accents (`#d4813a`/purples) → `''` (brand). `.force-dark` keeps pure-white primary text.
- **CRITICAL — data location:** `electron/main.ts` pins `app.setPath('userData', %APPDATA%/Wist)` so the Bard rebrand stays cosmetic and the real DB (`wist.db`) survives. Do NOT remove. Keep functional `wist` identifiers (IPC `window.wist.*`, backup marker `app:'wist'` in `electron/ipc/data.ts`, `wist.*` localStorage keys, `com.wist.app` appId).

## 3. Build & release workflow (do this after each module)
- Typecheck/build: `npm run build` (= `tsc --noEmit && vite build`).
- Installer: `npm run dist` → NSIS exe in `C:\Users\user\Desktop\Wist\release\` as `Bard Setup <ver>.exe`. appId unchanged → upgrades in place, data preserved.
- After each module: build green → bump `package.json` version → commit → `npm run dist`.
- **Never push to GitHub** without giving a change report + verification steps and getting approval first.
- Each feature was adversarially reviewed (subagent/workflow finds bugs → fix) before shipping. Keep doing this.
