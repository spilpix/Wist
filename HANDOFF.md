## Что за проект
**Bard** (внутр. имя `wist`) — десктоп «второй мозг»: **Electron 33 + React 18 + TypeScript + better-sqlite3**, локальное (local-first) + портативный «мозг» (.md/JSON зеркало). Цель: уровень **Notion / Obsidian / Capacities**.
**Угол (дифференциатор):** локальный связанный второй мозг, где заметки + задачи + НАСТОЯЩИЙ холст живут в одном графе знаний.
Ветка: `reskin/workspaces`. Версия package.json: `0.74.0`. Язык общения с пользователем: **русский**.

## Сборка и проверка
- Типы/сборка: `npm run build` (= `tsc --noEmit && vite build`) — главный гейт.
- Установщик: `npm run dist` → `release/Bard Setup 0.74.0.exe`.
- Рантайм: electron-скрипты `scripts/*.cjs`, запуск `npx electron scripts/<file>.cjs`.
  - ⚠️ **ИЗОЛЯЦИЯ:** скрипт, который СОЗДАЁТ/МЕНЯЕТ данные, ОБЯЗАН ставить `process.env.WIST_USER_DATA=<temp>` ДО `require('dist-electron/main.js')` (хук в `electron/main.ts`). **`process.env.APPDATA` на Windows НЕ работает** — Electron берёт путь из OS API → испортишь ЖИВУЮ БД (однажды случилось, почистили). Эталоны: `scripts/smoke-note-links.cjs`, `scripts/smoke-canvas-edges.cjs`.
